# changelog-reader

Чтение журнала изменений в формате [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/)
для OneScript: релизы и их разделы, блок «Не выпущено», заметки к версии готовым markdown
и выборка релизов по семантическим версиям и диапазонам semver.

Пригодится там, где журнал изменений — не только текст для людей: собрать описание
GitHub Release по тегу, проверить перед публикацией, что версия из `packagedef` описана
в `CHANGELOG.md`, показать в UI, что накопилось со времени последнего релиза.

Сравнение версий — семантическое, а не строковое: `1.10.0` старше `1.2.0`, а `1.0`
находит релиз `1.0.0`.

## Установка

```bash
opm install changelog-reader
```

В коде:

```onescript
#Использовать changelog-reader
```

Зависимости (ставятся автоматически): [`semver`](https://github.com/oscript-library/semver)
— разбор и сравнение версий, [`strings`](https://github.com/oscript-library/strings) —
разбор дат в заголовках релизов.

## Быстрый старт

```onescript
#Использовать changelog-reader

Журнал = ЖурналыПеремен.ИзФайла("CHANGELOG.md");

// заметки к релизу для тега, который сейчас публикуется
Релиз = Журнал.Релиз("1.2.0");
Сообщить(Релиз.Текст());

// что вышло последним
Сообщить(Журнал.ПоследнийРелиз().Версия());   // «1.10.0», а не «1.2.0»

// накопленное, но не выпущенное
Если Журнал.Неизданное() <> Неопределено Тогда
    Сообщить(Журнал.Неизданное().Пункты().Количество());
КонецЕсли;
```

## Формат журнала

```markdown
# Изменения

## [Не выпущено]

- ничего пока не накопилось

## [1.2.0] - 2026-02-01

### Добавлено

- выборка релизов по диапазону semver

### Исправлено

- дата без тире больше не теряется
```

Что читается:

- заголовок релиза — `## [1.2.0] - 2026-02-01`, `## 1.2.0 - 2026-02-01`, `## [v1.2.0]`,
  с датой и без неё; дата понимается в виде `2026-02-01` и `01.02.2026`;
- блок «Не выпущено» — `## [Не выпущено]` либо `## [Unreleased]`;
- разделы релиза — `### Добавлено`, `### Исправлено` и любые другие;
- пункты — строки списка `-`, `*`, `+`.

Заголовок, версию которого не принял semver (`## [следующий]`), релизом библиотека
не считает: такой блок в выборки не попадает и разбор не роняет.

## API

### Модуль `ЖурналыПеремен`

| Метод | Что делает |
| --- | --- |
| `ИзФайла(Путь, Кодировка = "UTF-8")` | Читает и разбирает файл журнала. Нет файла — исключение с путём |
| `ИзТекста(Текст)` | Разбирает журнал из строки |

### Класс `ЖурналПеремен`

| Метод | Что возвращает |
| --- | --- |
| `Релизы()` | Массив `РелизЖурнала` от самого свежего к самому старому |
| `ВерсииРелизов()` | Массив строк версий в том же порядке |
| `ПоследнийРелиз()` | Самый свежий релиз либо `Неопределено` |
| `Релиз(Версия)` | Релиз по версии; сравнение семантическое, приставка `v` допускается |
| `ЕстьВерсия(Версия)` | Булево |
| `РелизыВДиапазоне(Диапазон)` | Релизы, попавшие в диапазон semver: `^1.0`, `>=1.2.0 <2.0.0`, `1.x` |
| `Неизданное()` | Блок «Не выпущено» либо `Неопределено` |

### Класс `РелизЖурнала`

| Метод | Что возвращает |
| --- | --- |
| `Версия()` | Версия как написана в журнале, без приставки `v`; `""` у блока «Не выпущено» |
| `ДатаРелиза()` | Дата релиза; пустая дата, если её нет или она не разобрана |
| `Заголовок()` | Текст заголовка без решёток |
| `ЭтоНеизданное()` | Булево |
| `ИменаРазделов()` | Имена разделов в порядке появления |
| `ЕстьРаздел(Имя)` | Булево; регистр имени не значим |
| `Пункты(ИмяРаздела = "")` | Пункты раздела без маркеров; без имени — все пункты релиза |
| `Разделы()` | Соответствие «имя в нижнем регистре → массив пунктов» |
| `Текст()` | Тело релиза как есть — готовые заметки к релизу |

## Примеры

Проверка перед публикацией, что выпускаемая версия описана в журнале:

```onescript
#Использовать changelog-reader

Журнал = ЖурналыПеремен.ИзФайла("CHANGELOG.md");
Если НЕ Журнал.ЕстьВерсия(ВыпускаемаяВерсия) Тогда
    ВызватьИсключение "Версия " + ВыпускаемаяВерсия + " не описана в CHANGELOG.md";
КонецЕсли;
```

Что изменилось в поддерживаемой ветке 1.x:

```onescript
Для Каждого Релиз Из Журнал.РелизыВДиапазоне("^1.0") Цикл
    Сообщить(Релиз.Версия() + " (" + Формат(Релиз.ДатаРелиза(), "ДФ=dd.MM.yyyy") + ")");
    Для Каждого Пункт Из Релиз.Пункты("Исправлено") Цикл
        Сообщить("  - " + Пункт);
    КонецЦикла;
КонецЦикла;
```

## Разработка

```bash
opm install -l     # зависимости в ./oscript_modules
oneunit execute    # тесты
opm build .        # сборка пакета .ospx
```

Публикация в хаб выполняется доверенным конвейером (OIDC, без долгоживущих токенов
в секретах репозитория) — [.github/workflows/publish.yml](.github/workflows/publish.yml).
Конвейер запускается по пушу тега.
